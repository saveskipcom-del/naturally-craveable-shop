# Naturally Craveable — Ebook Shop

Static shop site for the Naturally Craveable ebook series, hosted on GitHub Pages at https://craveable.click

- Book 1 (live): Naturally Craveable: Healthy Cravings — 120 recipes, $29.99 — PayPal checkout, instant PDF download.
- Books 2 & 3: coming soon.

The PayPal client ID in index.html is a public identifier (it appears in the
PayPal SDK URL on every checkout page). No secret is stored in this repo.
